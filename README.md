# AI in Materials Science - Megha

## 📖 Introduction
This project explores applications of **Artificial Intelligence in Materials Science**, focusing on predictive modeling and data-driven discovery. It provides workflows, datasets, and educational modules to help students and researchers understand how machine learning can accelerate materials research.

## 🎯 Objectives
- Apply **machine learning** to material property prediction  
- Build **educational modules** for students and researchers  
- Demonstrate **workflows** with datasets and notebooks  

## 📂 Project Structure
- **Module-1**: Contains the first learning module with code and examples  
- Additional modules will be added to expand coverage of AI applications in materials science
